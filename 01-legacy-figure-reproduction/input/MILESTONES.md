# Milestones

1. Read the brief and define the target output
2. Confirm the environment runs
3. Generate the code that produces the draft figure output
4. Compare the output to the target figure, identify discrepancies
5. Do not overwrite the generated figures, instead number them sequentially to track the progress and keep them for comparison
6. Iterate on the code to improve the figure, guided by the identified discrepancies
7. Refactor the code if needed for clarity
8. Document assumptions or approximations made in the process
9. Explore parameter choices that affect the output and document them

## Suggested Git Checkpoints

- `Initialize figure reproduction scaffold`
- `Create first draft figure`
- `Document assumptions and clean up workflow`
- `Finalize reproducible demo state`
