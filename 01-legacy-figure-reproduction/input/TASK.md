# Task

Reproduce target figure 1 from the scientific paper in a transparent, reviewable way.

## Success Criteria

- One figure is reproduced or approximated clearly
- Assumptions and deviations are written down
- The project structure remains understandable to another researcher

## Scope Notes

- Focus on one figure, not the whole paper
- Prefer clarity and reproducibility over visual perfection
- Do not reproduce the paper's method or results exactly, just do necessary approximations to get a similar figure

## Technical approach

- Analyze the figure and its description, refer to `DATA.md` for details on the figure's content and context
- Use Python with libraries like Matplotlib, NumPy, and possibly SciPy for numerical calculations.
- For reproducibility, prepare a conda environment file `environment.yml` with all dependencies.
- Name the environment `exercise_1_legacy_figure_reproduction`
- Refer to `OUTPUTS.md` for the expected deliverables and structure.
- Use the `MILESTONES.md` as a step-by-step guide for the implementation process.
